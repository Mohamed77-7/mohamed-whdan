HTML Complete Guide

HTML (HyperText Markup Language) defines the structure and meaning of content on a web page using elements and tags.

1. Document Structure & Tags

Every HTML document follows a basic structural skeleton with opening and closing tags.

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Page Title</title>
</head>
<body>
    <h1>Main Heading</h1>
</body>
</html>

2. Core Elements & Attributes

  • Headings & Paragraphs: Use <h1> to <h6> for headings and <p> for text blocks.
  • Attributes: Provide extra information like href in <a> or src and alt in <img>.
  • Semantic Tags: Elements like <header>, <nav>, <main>, <section>, and <footer> clarify page structure.

3. Common Tags Reference

Tag Purpose
<a> Creates a hyperlink to another page or resource.
<img> Embeds an image into the page.
<form> Collects user input through fields and controls.
