About WebBasics

WebBasics is an educational guide dedicated to explaining HTML and CSS in depth, built around core concepts and practical sections covered throughout the academic year.

1. Why This Website Exists

  • Provides a clear, structured reference for mastering HTML structure and CSS styling.
  • Organizes foundational topics in one place so you can revise quickly and build clean pages.
  • Connects core theory with hands-on examples and practical layout patterns.

2. Based on Year-Round Sections

  • Built from the topics and practical sections practiced across the year.
  • Covers document structure, tags, attributes, text formatting, tables, forms, and semantic elements in HTML.
  • Covers selectors, box model, colors, typography, flexbox, and layout styling in CSS.

3. How to Navigate the Guide

  • Home (project.html): Overview of the guide and interactive flip cards for HTML and CSS.
  • HTML (project2.html): Detailed breakdown of HTML tags, structure, media, and forms.
  • CSS (project3.html): Core styling rules, box model, flexbox, and common properties.
