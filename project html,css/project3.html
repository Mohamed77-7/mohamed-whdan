CSS Complete Guide

CSS (Cascading Style Sheets) is responsible for the styling, layout, and responsiveness of HTML elements.

1. Syntax and Selectors

CSS rules consist of a selector and a declaration block.

selector {
    property: value;
    color: #38bdf8;
}

2. Core Concepts

  • Box Model: Every element is wrapped in a box comprising margin, border, padding, and content.
  • Colors and Fonts: Properties like color, background-color, and font-family dictate typography and theme.
  • Flexbox: A layout module designed for distributing space along a single axis.

3. Common Properties Reference

Property Function
margin Clears an area outside an element's border.
padding Clears an area around the content inside an element.
